# サラダパズル

カロリーと栄養素をお題どおりにピッタリ合わせる、ドット絵（2D見下ろし）のサラダのパズルゲームです。
スマホ向け（PCでも遊べます）。`index.html` 1ファイルだけで動きます（ビルド不要）。

## あそびかた
- 具材をボウルへドラッグ＆ドロップして盛りつけ（タップでも置ける）。あとから置いたものほど上に重なる
- 具材をタップでえらび、ドラッグで移動・四隅の□で拡大縮小・●で回転（スマホは2本指ピンチ、PCはホイール／Shift＋ホイール）。大きさに合わせてグラム数が変わる
- 左の「いれたもの」はレイヤー一覧（具材ごとのグラム表記つき）。行をそのままドラッグ（スマホは少し長押し）や ▲▼ で重なり順を変更、複製・削除も。ドレッシングは一番上の別枠に固定で、タップするとかけるモードに
- 右上に、いまのサラダの点数（100点満点）を常に表示
- ドレッシングは種類を選んで、ボウルを指やマウスでなぞってかける（細・太・ふきとる）。にじんだ液体のように描画。なぞった量がそのままグラム数になる（細い線でボウルを3回横切る≒大さじ1＝15g、太線は2倍、最大60g）
- カロリー／たんぱく質／脂質／炭水化物／食物繊維／塩分／盛り付け率（ボウルの底が具材でおおわれている割合）＋お題ごとの特別目標を緑のゾーンに入れる
- 採点は2モード：「通常」＝目標の範囲に入れば100点／「精密」＝各目標の真ん中にどれだけ近いかを小数点まで採点（メーターの黒線が真ん中）。ベスト記録はモード別
- 全部そろうと PERFECT!!（紙吹雪）。結果は2枚の投稿用画像（どちらも1080×1350固定、タップで拡大・1枚ずつ保存も可）にできる：1枚目「サラダ・評価と点数・栄養素・目標チェック」、2枚目「レシピ（アイコン・グラム・個数の目安）」
- 「Xに投稿」は3ステップ（画像を保存 → Xをひらく → 添付）。共有シートが使える環境では「画像2枚つきで共有する」も出る（リンクはゲームのURL）
- 結果画面は「Xに投稿」「Instagramに投稿」のタブで切りかえ（はじめは X）。「Instagramに投稿」タブ：ストーリーズ用の縦長画像（1080×1920、上下はインスタの表示がかぶるので大事なものは真ん中）、盛りつけのタイムラプス動画（縦長・約8秒。具材が置いた順に乗っていき、ドレッシング→結果→ゲームの案内。端末のブラウザで録画して MP4（対応していなければ WebM）で保存）、ハッシュタグつきの文（インスタの本文はリンクを押せないので URL は文字だけ）。スマホでは共有メニューから直接インスタに送れる
- スマホでは左の一覧がアイコン＋グラムの細い列になり、「一覧▸」で名前つきに広がる。タップしやすいようボタンを大きめに

## お題
- 1日3つ：端末の時計で、朝（5時〜）・昼（11時〜）・夜（17時〜）のいまの時間帯のお題が出る
- 端末のタイムゾーン（なければ言語設定）から国を判定して表示。結果カードにも国名が入る
- タイトル画面のお題カードに、栄養素の目標（たんぱく質・脂質・炭水化物・食物繊維・塩分など）を表示
- 日付からシード生成するので、同じ日は誰でも同じお題
- お題は「実際に作れるお手本サラダ（盛り付けまで）」から逆算して作るので、必ずPERFECTが出せる
- お題は34種類。同じ名前のお題でも、日によってボウルの大きさ・カロリー帯・目標値・むずかしさ（★1〜★3＝目標の幅がひろい〜せまい）が変わる
  - 栄養：バランス／高たんぱく／低糖質／食物繊維たっぷり／ビタミンCチャージ／カルシウム強化／鉄分補給／減塩／彩り／低脂質／エネルギーチャージ／具だくさん／かるめサラダ／たんぱく質多め・脂質ひかえめ／鉄とビタミンC／カルシウムとたんぱく質／フルーツたっぷり／豆パワー／ナッツ＆シード
  - ルール系：シンプル（N種以内）／素材の味（ドレッシングなし）／シーフード／ベジタリアン
  - 料理風：コブサラダ風／シーザーサラダ風／カプレーゼ風／ニース風／和風サラダ／中華風サラダ／豆腐サラダ／ポテサラ風／マカロニサラダ風／地中海風／イタリアン
- お題には「主菜サラダ」と「副菜サラダ」があり、カードやゲーム画面に表示する（下の「お題の目安」の範囲でお手本を作る）
- 量が少ないお題（副菜サラダなど）は、具材がスカスカに見えないようボウル（お皿）の見た目を小さくする（最小6割）
- 「れんしゅう」はランダムなお題（記録なし）

## お題の目安
お題の目安は『日本人の食事摂取基準（2025年版）』などを参考に、ごはんと合わせた1食を想定しています（トップ・あそびかたにも表示）。

| 種類 | カロリー | 脂質 | たんぱく質 | 塩分 | 野菜 | もとにしたもの |
|---|---|---|---|---|---|---|
| 主菜サラダ | 220〜400kcal | 20g以下 | 10〜30g | 2.0g以下 | 140g以上 | スマートミール「ちゃんと」（1食450〜650kcal未満・食塩3.0g未満・野菜等140g以上・P13〜20%E・F20〜30%E）から、ごはん150g（234kcal・たんぱく質3.8g・脂質0.5g）の分を引いた値 |
| 副菜サラダ | 60〜200kcal | 10g以下 | 15g以下 | 1.0g以下 | 70g以上 | 食事バランスガイドの副菜（1つ＝野菜など約70g）をもとにしたゲーム上の配分 |

- 野菜は「野菜等（野菜・きのこ・海藻・いも）」の重さ（葉物＋野菜のカテゴリ。アボカドは果実なので除く）。お題の目標にも「野菜 ○g以上」が入る
- 主菜だけのテーマ：高たんぱく／エネルギーチャージ／たんぱく質多め・脂質ひかえめ／カルシウムとたんぱく質／シーフード／コブ風／ニース風／シーザー風／ポテサラ風／マカロニサラダ風。副菜だけ：かるめサラダ／フルーツたっぷり／低糖質（ごはんと合わせる前提なので、サラダ側をひかえめにする副菜として）。ほかは日によってどちらか（朝は副菜が多め）
- 数値は `index.html` の `KINDS` で変更できる。参考：1日の目標は食塩 男性7.5g・女性6.5g未満、脂質20〜30%E、食物繊維 男性20〜22g・女性18g以上（食事摂取基準2025）、野菜350g・果物200g（健康日本21 第三次）
- いずれも国民全体向けの目安をゲーム用に配分したもので、個人の食事指導ではありません

## オリジナルのお題
- トップの「オリジナルのお題をつくる」で、名前・ボウルの大きさ・種類（主菜／副菜／指定なし）・各目標（カロリー／たんぱく質／脂質／炭水化物／食物繊維／塩分／野菜／盛り付け／ビタミンC／カルシウム／鉄／彩り／具材の種類）の下限・上限、ドレッシングなしを自由に決めてお題をつくれる（空らんは制限なし）
- 「ひな形」から、きょうのお題や各テーマを選ぶと、えらんだボウルの大きさ・サラダの種類に合わせた数値が入る（そこから調整できる）
- 保存時に、目標をすべて満たすお手本サラダを自動でさがす（見つかれば PERFECT が出せることを確認ずみ、結果画面にお手本も出る）
- 「共有」でお題のリンク（`https://toyogame.github.io/salad-puzzle/#q=コード`）をコピー。開くとお題が追加される。コードを「もらったお題を追加」に貼ってもよい
- 記録はお題ごと。投稿文のリンクもそのお題のリンクになる（GitHub Pages 版）

## 食材
- はじめは「おすすめ」の60種（UI的にちょうど使いやすい数）。トップの「食材」ページで、追加の43種（大葉・みょうが・春菊・かいわれ・長いも・しめじ・ちりめんじゃこ・塩昆布・天かすなど、日本でなじみのある食材が中心）を選んで使えるようにしたり、苦手な食材を外したりできる（葉物1つ以上・合計8つ以上）
- お題は「おすすめ」の食材だけで作るので、食材設定に関係なくみんな同じお題になる
- ドレッシング12種

## 栄養データ
- 画面にも「カロリー・栄養素の数値はゲーム上の目安です。実際の食品とは異なる場合がありますので、あらかじめご了承ください。」と表示しています
- ほとんどの食材は「日本食品標準成分表（八訂）増補2023年」の値（ゆで・水煮など、サラダで使う状態に近い食品）をもとにしています
- 成分表に該当がない食品（蒸し鶏・ボイルえび・揚げ玉ねぎ・トルティーヤ・ミックスビーンズなど）は、近い食品や市販品をもとにした目安、キヌアは米国農務省（USDA）の成分データをもとにした目安です
- 「食材」ページで各食材の「i」を押すと、1人前と100gあたりの値と出典の種類を確認できます
- 値はゲーム上の目安（概算）です。結果画面には使った具材の分量を「レシピ」として表示します。実際の栄養や健康への効果を保証するものではありません

## 音・チュートリアル
- BGM（ゆるいチップチューン）と効果音はその場で合成。トップの「音」で個別にオン・オフ（最初の操作のあとに鳴り始める）
- はじめての人向けの30秒チュートリアル（トップのお知らせ、または「？」から。やらなくても遊べる）

## 多言語
- 日本語／English／简体中文／繁體中文／한국어。端末の言語設定で自動で切りかわり、トップの 🌐 で変更できる（`?lang=en` などでも指定可）。日本語・中国語・韓国語以外の言語の端末は英語
- 文は「日本語の文」をキーにした翻訳表 `i18n.json` にまとめてある。コードでは `T('日本語の文')`（差しこみは `T('{0}点', 92)`）で引く。食材・お題・ドレッシングの名前は言語を切りかえたときに置きかえる
- 文を足したり変えたりしたら `i18n.json` に訳を足して `python3 tools/i18n_embed.py` で `index.html` に埋めこむ（訳のもれは `smoke_test.js` が教えてくれる）
- 翻訳はネイティブチェック前の下訳。気になるところは `i18n.json` を直すだけで反映できる
- お題（日付ごとの数値）はどの言語でも同じ。投稿文は日本語だけ全角そろえ、ほかの言語は「見出し: 値」の形で、ハッシュタグは `#SaladPuzzle`

## 配信・SNS投稿
ゲーム実況・配信・SNSへの投稿は自由です（トップとあそびかたにも表示）。

## バージョン
- タイトル画面のいちばん下に `v1.0.0` のように表示。更新するたびに `index.html` の `VERSION` を上げて、`CHANGELOG.md` に内容を書く（不具合の修正＝3つ目、機能の追加＝2つ目）

## 改行
- 日本語は文節（意味のまとまり）で改行する。Google の BudouX の日本語モデル（Apache License 2.0）を `index.html` に埋めこみ、文の区切りにゼロ幅スペースを入れて `word-break:keep-all` で折り返す（Safari でも同じ）
- 長い食材名などで区切りを足したいときは `BX_WORDS` に `'サラダ|ほうれん草'` の形で足す

## 開発用
- `?unlock=1` を付けると時間に関係なく3つのお題を全部遊べます
- 記録・作りかけ・設定は localStorage に保存
- claude.ai アーティファクト版を作る: `python3 tools/build_artifact.py`（`dist/salad-artifact.html` に出力）
- 動作チェック: `node tools/smoke_test.js`（アーティファクト版は `--artifact`）。Playwright が必要
- OGP画像・アイコンの作りなおし: `node tools/make_images.js --font-css <@fontsource/dotgothic16 の 400.css>`（`ogp.png` と言語別の `ogp-en.png`・`ogp-zh-hans.png`・`ogp-zh-hant.png`・`ogp-ko.png`、`icon.png`）
- 言語別の入口ページの作りなおし: `python3 tools/lang_pages.py`（`en/`・`zh-hans/`・`zh-hant/`・`ko/`）

## 公開（GitHub Pages）
- このリポジトリの Settings → Pages で「Deploy from a branch」→ `main` / `(root)` を選ぶと `https://toyogame.github.io/salad-puzzle/` で遊べます
- 投稿文・オリジナルのお題のリンクは、日本語なら `https://toyogame.github.io/salad-puzzle/`、ほかの言語なら `…/en/`・`…/zh-hans/`・`…/zh-hant/`・`…/ko/`。言語別のURLはXなどのカード（タイトル・説明・画像）がその言語になる入口ページで、開くとすぐゲーム本体に移る（ゲームの言語は端末の設定で決まる）
- 公開先が変わったら `index.html` の `GAME_URL` と `og:url`・`og:image`、`tools/lang_pages.py` の `SITE` を書きかえて、入口ページを作りなおす

## アクセス解析（GoatCounter）
- GoatCounter（https://toyogame.goatcounter.com）で計測。`index.html` の `<!-- ANALYTICS -->` のところにタグ、`ANALYTICS={enabled:true}` で有効。Cookie を使わないので同意バナーは不要。トップ画面の注意書きにも明記
- ページの閲覧数（国・言語・端末・どこから来たか）は自動で数える。ゲーム内の操作は「イベント」として `event/…` のパスで記録（主な値はパスに入れる。例：`event/challenge_finish/normal/PERFECT`、`event/app_open/en`）
- 送るイベント：`app_open`（言語）／`challenge_start`（時間帯・モード）／`challenge_finish`（モード・ランク）／`share_open`／`share_x`／`share_native`／`image_save`／`share_copy`／`tutorial_start`・`tutorial_done`・`tutorial_skip`／`ingredients`／`mode`／`lang`／`custom_save`／`custom_share`／`custom_import`
- 個人情報や投稿コメントの本文は送りません。アーティファクト版（`build_artifact.py`）では解析を外します
- ほかのサービス（Google アナリティクス4・Plausible・Googleタグマネージャー）に替える場合は、タグを差しかえるだけで `track()` がそのまま使えます
